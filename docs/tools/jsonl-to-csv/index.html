Frequently asked questions

How do I export JSONL from Apify?

Open the run’s output or dataset in Apify Console, select Export, choose JSON or JSONL, and download the file. Apify offers a direct CSV export too. Apify export guide

What happens to nested objects and arrays?

Nested objects become dotted columns. Arrays stay together as JSON text in a single cell. Missing fields and null values produce blank cells. Dots and backslashes in literal keys are escaped so similar column names remain distinct.

How does the converter handle spreadsheet formulas?

It prefixes formula-like text and headers with an apostrophe and quotes CSV fields. Import columns as text if you need spreadsheet software to preserve data types such as leading-zero IDs.

Are my data and files uploaded?

Conversion and download happen in your browser. The converter sends no dataset or analytics requests.

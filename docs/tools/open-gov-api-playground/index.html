Developer FAQ

How do I call the SEC EDGAR filings API from Python or curl with maxTotalChargeUsd?

POST https://api.apify.com/v2/acts/8LFIbRbidiHPknMz5/run-sync-get-dataset-items?maxTotalChargeUsd=0.25 with Authorization: Bearer $APIFY_TOKEN and JSON input {"mode":"search","query":"artificial intelligence","forms":"10-K,10-Q,8-K","startDate":"2025-01-01","maxItems":25}. Passing maxTotalChargeUsd as a query parameter enforces a hard server-side spend cap.

How can I build a ClinicalTrials.gov n8n workflow without runaway billing?

Import the Public KVS n8n JSON workflow (n8n-clinical-trials-csv.json) for Actor KchE3qKKrwU0rCe9f, store APIFY_TOKEN as an n8n environment variable, keep retryOnFail set to false, and keep maxTotalChargeUsd=0.25 in the sync URL. 25 studies at $3.50/1K plus $0.00005 start fee costs ~$0.08755.

When does Apify Pay-Per-Event beat RapidAPI Basic, Pro, or Ultra subscriptions?

RapidAPI Basic ($0/mo) includes 100 rows/month for free testing. Above 100 rows/month, Apify PPE (0% Free, -5% Starter, -15% Scale, -25% Business discounts plus flat $0.00005 start fee) beats RapidAPI Pro ($19/mo, 5,000 rows) for lower or bursty volume, while RapidAPI Pro ($19) or Ultra ($49, 25,000 rows) saves money near monthly quota. Above 25,000 rows/month, Apify PPE scales linearly with maxTotalChargeUsd caps.

How is openFDA Recalls REST API row metering calculated on RapidAPI?

GET /v1/openfda/records returns {"items":[...]} with limit 1..20 per request and X-RapidAPI-Billing: Rows=N where N equals returned records. Error responses and /health return Rows=0.

What is included in Official MCP Registry v1.0.2 (io.github.Rainy-fall-end/china-public-data-tools)?

Version 1.0.2 exposes 8 live paid Global and APAC Apify Actors over Streamable HTTP (SEC EDGAR, ClinicalTrials.gov, UK Gov Tenders, Singapore BCA Green Mark, CN Finance News, ModelScope, TapTap, SMZDM). Authenticate with Apify OAuth or Authorization: Bearer $APIFY_TOKEN.

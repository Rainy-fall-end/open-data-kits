Frequently Asked Questions

How do Apify Pay-Per-Event start fees work?

The preset Actors charge one start event per GB of allocated memory, with a minimum of one per run. At 512 MB that adds $0.00005 per run.

What discounts do paid Apify plans apply to PPE events?

UK Contracts Finder charges the same event price in every tier. The other listed presets discount result events by 5% on Bronze, 15% on Silver and 25% on Gold and above. For Custom, enter your effective event rate.

What is maxTotalChargeUsd and how do I use it?

maxTotalChargeUsd is a run option that limits the event charges for one run. Supply it as a query parameter when using the HTTP API.

What is the creator 80/20 net payout split?

Only paid users contribute to creator profit. This estimate deducts the 20% Apify share and estimated compute from paid-user event revenue. Storage, proxy and other platform costs may also apply.

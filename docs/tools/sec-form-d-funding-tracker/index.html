FREQUENTLY ASKED QUESTIONS

        
What buyers ask before the first run.

        
What does Form D funding mode return?
It returns entity-level offering facts such as issuer, industry group, exemptions, security types, offering amount, amount sold, minimum investment, investor count, and filing identifiers.
Can the same Actor return 10-K and 10-Q data?
Yes. XBRL mode normalizes eight core US-GAAP metrics into one record per fiscal period for a ticker or CIK.
Is SEC EDGAR data commercially reusable?
The source is U.S. Government public-domain data. The Actor adds parsing and normalization; each output includes source and license metadata for downstream audits.
How is spend limited?
Every generated example uses maxTotalChargeUsd=0.25. The platform enforces that cap, and the Actor stops when the dataset-item charge limit is reached.
